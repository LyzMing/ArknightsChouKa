## 抽卡视频

`抽卡视频/` 按原视频文件名分为 `六星/`、`五星/`、`四星/`、`白光/`，各 1 段。这些是抽卡演出档位，尚未与上述奖品等级建立对应关系。

视频文件路径由 `../videos.js` 提供给页面。新增或更名视频后，在 `ChouKaMoNi` 目录运行 `node tools/scan.mjs`；Windows 也可运行 `刷新视频列表.bat`。

## 60 FPS 拉包帧

页面播放片头和揭晓段时仍使用原始 MP4；鼠标控制的拉链区间使用预先解码的 60 FPS WebP 帧，避免拖动时频繁修改视频进度造成卡顿。

- 生成结果在 `抽卡帧/`，当前四档共 637 帧。
- `../pull-frames.js` 记录每段帧缓存的时间范围、帧率、尺寸和路径。
- 帧缓存会在校准起止时间两侧各多解码 0.4 秒，小范围修改校准不需要重新生成。
- 如果更换视频，或校准超出缓存范围，先运行 `启动模拟器.bat`，再运行 `生成拉包帧.bat`，点击“开始生成”。
- 生成工具位于 `../tools/extract-frames.html`，使用浏览器自身的视频解码器，不影响正式活动时的离线运行。
